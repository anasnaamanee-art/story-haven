# مذاكر — مساعدك الدراسي الذكي 📚

تطبيق دراسي كامل يعمل على جهازك (أو خادمك) **مجاناً وبلا حدود**: يحمّل مئات الملفات الضخمة، يجيب على أسئلتك من محتواها مع ذكر الصفحة، يولّد تمارين مشروحة، يشرح المواضيع بمستويات مختلفة، يبحث في الويب، ويبني خطة مراجعة — كل ذلك **بالعربية والفرنسية**.

> لا اشتراك، لا مفاتيح API، لا حدّ لعدد الأسئلة أو الملفات. البحث الداخلي (BM25) والتلخيص والتمارين تعمل على جهازك بلا إنترنت. البحث الخارجي يستخدم ويكيبيديا و DuckDuckGo و arXiv مجاناً.

---

## ⚡ التشغيل

```bash
cd mudhakir
npm install
npm start
# → http://localhost:3000
```

متغيّرات اختيارية:

| المتغيّر | الافتراضي | المعنى |
|---|---|---|
| `PORT` | `3000` | منفذ الخادم |
| `DATA_DIR` | `./data` | مكان تخزين المكتبة والفهرس |
| `MAX_FILE_BYTES` | 3 غيغابايت | أقصى حجم لملف واحد |
| `UPLOAD_CONCURRENCY` | `4` | عدد الملفات التي تُعالَج بالتوازي |

## ✨ ما يفعله

### 1) مكتبة ملفات ضخمة
- يقرأ: **PDF, DOCX, DOC, PPTX, XLSX/XLS, CSV/TSV, EPUB, TXT, MD, HTML, XML, JSON, TEX, SRT, RTF**، وصوراً عبر OCR (اختياري).
- اسحب **حتى ٣٠٠ ملف** دفعة واحدة، وكل ملف حتى **٣ غيغابايت**.
- الرفع يتم على القرص (لا في الذاكرة) ثم تُفهرس المقاطع، فتظل الذاكرة منخفضة مع آلاف الصفحات.
- يحذّرك عندما يكون الملف ممسوحاً ضوئياً أو بترميز خطوط تالف (تقييم جودة لكل مستند).
- عرض المستند، ملخص تلقائي، واستخراج المحاور والتعريفات.

### 2) أسئلة وأجوبة من محتوى ملفاتك
- بحث **BM25 عربي/فرنسي** مع تطبيع (همزات، تشكيل، ة/ه، ى/ي) وحذف كلمات التوقف.
- الإجابة تُركَّب من **جمل مستخرجة من مستنداتك**، مع ترجيح المصطلحات النادرة وذكر **الصفحة والمصدر** لكل جملة.
- زر **«بحث الويب»** لإضافة مصادر خارجية عند الحاجة.

### 3) تمارين مشروحة
أنواع: **اختيار من متعدد، صواب/خطأ، إكمال الفراغ، سؤال مقالي** — تُولَّد من جمل ملفاتك فعلياً، مع:
- شرح لكل إجابة ومرجع الصفحة.
- تصحيح فوري ونتيجة، وتقييم الأسئلة المقالية بمقارنة الكلمات المفتاحية.
- تصدير الورقة إلى **PDF** عبر الطباعة.

### 4) اشرح لي
شرح بثلاثة مستويات (تبسيط شديد / متوسط / معمّق) مع ملخص، تشبيه، مصطلحات مفتاحية، وخطوات مذاكرة.

### 5) بحث عن أي موضوع
ويكيبيديا (عربي/فرنسي/إنجليزي) + نتائج الويب + أوراق arXiv — مع زر **«أضف إلى مكتبتي»** لتحويل أي مقال إلى مادة تذاكرها وتسألها.

### 6) بطاقات مراجعة
مصطلح ← تعريفه، مستخرجة من جمل التعريف في ملفاتك («X هو …»)، مع كشف الجواب والخلط.

### 7) خطة مراجعة
توزّع محاور ملفاتك على أيام مع جلسات استرجاع نشط وتمارين.

### 8) واجهة عربية/فرنسية
تبديل فوري بين العربية (RTL) والفرنسية (LTR)، ووضع ليلي، وتصميم يعمل على الهاتف والحاسوب.

## 🧠 كيف يعمل (باختصار)

```
رفع → استخراج نص (pdfjs / mammoth / jszip / xlsx)
   → تقطيع لمقاطع مع تداخل + تقييم جودة
   → فهرس BM25 على القرص (data/docs/*.json + index.json)
سؤال → استرجاع مقاطع → اختيار أفضل الجمل (تغطية مصطلحات موزونة)
     → تركيب إجابة + مراجع → إجابة منظمة
تمارين → اختيار جمل غنية + استخراج مصطلحات (مع كشف الأفعال)
       → توليد مشتّتات من نفس المستند → شرح + مصدر
```

كل شيء محلي: **لا تُرسل ملفاتك إلى أي خدمة خارجية**، إلا إذا استخدمت تبويب البحث أو فعّلت «بحث الويب».

## 📁 البنية

```
mudhakir/
├── server.js            # واجهة HTTP (Express): رفع، سؤال، تمارين، بحث، خطة…
├── lib/
│   ├── library.js       # مخزن المستندات + فهرس BM25 + المحاور
│   ├── extract.js       # استخراج النص من كل الصيغ
│   ├── compose.js       # اختيار الجمل وتركيب الإجابة
│   ├── exercises.js     # توليد التمارين والبطاقات والتقييم
│   ├── summarize.js     # تلخيص، شرح، خطة
│   ├── search.js        # ويكيبيديا / DuckDuckGo / arXiv
│   └── util.js          # تطبيع عربي، تقطيع، جودة النص
├── public/index.html    # الواجهة (عربي/فرنسي، بلا أي مكتبة خارجية)
└── data/                # مكتبتك (يُنشأ تلقائياً — غير مُدرج في git)
```

## 🔒 الخصوصية والحدود

- ملفاتك تبقى في `data/` على جهازك.
- البحث في الويب يحتاج اتصالاً بالإنترنت؛ باقي الميزات تعمل بلا إنترنت.
- ملفات PDF المصوّرة (Scan) تحتاج OCR: `npm i tesseract.js` ثم أعد رفع الصورة/الملف.

## 🛠️ استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| «لم يتم استخراج نص» | الملف صور ممسوحة — استخدم نسخة نصية أو شغّل OCR |
| أسماء ملفات عربية مشوّشة | حدّث المتصفح؛ الخادم يعالج ترميز أسماء multer تلقائياً |
| البحث الخارجي لا يعيد نتائج | تحقّق من اتصال الإنترنت/الجدار الناري في الخادم |
| بطء مع ملفات كثيرة | ارفع على دفعات، أو زد `UPLOAD_CONCURRENCY` |
